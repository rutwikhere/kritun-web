# Kritun Web

Official brand campaign website for **KRITUN** — The social and community platform built for gamers.

## Tech Stack
- Semantic HTML5
- Vanilla CSS3 (Custom Design System)
- Vanilla JavaScript

## Brand Aesthetics
- Dark obsidian palette (`#040406`)
- Signature crimson accents (`#E53935`)
- Editorial typography (`Outfit` & `Inter`)
- Responsive design for all screen sizes

## Deployment
Static site ready for deployment on GitHub Pages, Vercel, Netlify, or Cloudflare Pages.
